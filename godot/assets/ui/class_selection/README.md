# Portrety klas

Ekran `Wybór Drogi` korzysta z ośmiu dedykowanych ilustracji — po jednej dla
każdej klasy i płci postaci:

- `warrior_male.png`, `warrior_female.png`
- `hunter_male.png`, `hunter_female.png`
- `mage_male.png`, `mage_female.png`
- `pierrot_male.png`, `pierrot_female.png`

Pliki są pionowymi PNG RGBA z rzeczywistym kanałem alfa i bez zintegrowanego
tła. Na kartach klas skrypt wyświetla ich górny, szeroki kadr, a pełna sylwetka
pozostaje dostępna do użycia w rozbudowanym panelu szczegółów. Jeśli płeć
postaci nie została jeszcze określona, ekran używa wariantu żeńskiego jako
bezpiecznej wartości domyślnej.
