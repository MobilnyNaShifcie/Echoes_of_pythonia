# v0.20.0 — Lodowe Wybrzeże

## Zakres
- poziom 14-18, zagrożenie 5/5, Item Power VI,
- zwykli: Zamarznięty Rozbitek, Lodowy Niedźwiedź, Śnieżny Gryf, Lodowy Krab, Syrena Czarnego Morza,
- miniboss: Widmo Kapitana Statku,
- boss: Lewiatan Północy.

## Przedmioty klasowe
Przedmioty klasowe są **drop-only**. Nie mają receptur i można je założyć dowolną klasą; ich specjalny efekt działa wyłącznie dla wskazanej klasy.

- Pancerz Północy — Wojownik / Odwet,
- Płaszcz Śnieżnego Gryfa — Łowca / Drapieżny Odruch,
- Amulet Czarnego Morza — Mag / Przypływ Many.

Normalny drop: 2-2.5%. Elitarny odpowiednik: 7-8% przed wpływem pogody.

## Założenia itemizacji
- brak nowej broni w Regionie 5,
- Miecz Wielkiego Mistrza może pozostać sensowną bronią do Dungeon 2,
- materiały mają zastosowanie w kilku neutralnych recepturach, ale klasowych chase-itemów nie da się wycraftować,
- save schema pozostaje v9.
