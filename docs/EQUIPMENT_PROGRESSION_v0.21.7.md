# Equipment Progression Pass — v0.21.7

Celem aktualizacji jest uzupełnienie realnych luk w progresji slotów bez dodawania pełnego kompletu sprzętu dla każdego Item Power.

## Nowe szczeble

- Naszyjnik: `Medalion Utopionej Matki` — IP III, lvl 8.
- Bransoleta: `Bransoleta Zakonu` — IP IV, lvl 10.
- Pas: `Pas Pustkowi` — IP V, lvl 13.
- Bransoleta: `Bransoleta Czarnej Floty` — IP VI, lvl 17 (przebudowany dawny Kapitański Sygnet).

## Filozofia

Przedmioty tego samego IP nie powinny być automatycznie liniowymi zamiennikami poziom po poziomie. Bransoleta Czarnej Floty i Pierścień Lewiatana zajmują od v0.21.7 różne sloty. System przemian +10 pozostaje pomysłem na późniejsze, specjalnie zaprojektowane linie wyposażenia i nie jest częścią tej aktualizacji.
